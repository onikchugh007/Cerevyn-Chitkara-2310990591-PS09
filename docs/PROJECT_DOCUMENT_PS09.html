1. Executive Summary & Problem Formulation

Conventional browser memory games rely on non-deterministic randomization with fixed board sizes and opaque reset behaviors. Problem Statement 09 (PS09) requires developing an adaptive memory matching game that solves these challenges through:

  • Deterministic Board Generation: Entering the same seed produces the identical card arrangement using Mulberry32 PRNG.
  • Strict Concurrency Invariants: Third-card lockout during mismatch resolution, duplicate-click immunity, and zero ghost flips upon restart.
  • Explainable Cognitive Calibration: Mathematical evaluation calculating cognitive efficiency: Efficiency (%) = (Theoretical Minimum Moves / Actual Moves) × 100 with rule-based promotion to 6×6 (18 pairs) or demotion to 3×4 (6 pairs).
  • Procedural Audio: Zero external audio assets, synthesized dynamically via native HTML5 Web Audio API.
  • Universal Multi-Device Responsiveness: Fluid CSS Grid with minmax(0, 1fr) tracks, mobile landscape optimizations, and 44px+ touch targets.

3. Core Algorithms & State Machine Invariants

3.1. Deterministic Mulberry32 PRNG

Seeds are converted to 32-bit unsigned hashes via FNV-1a, then passed to the Mulberry32 generator for uniform random distributions in [0, 1):

function mulberry32(seed) {
  return function() {
    let t = seed += 0x6D2B79F5;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

3.2. Concurrency Safety Rules

  • Third-Card Lockout: When 2 unmatched cards are revealed, isResolvingPair = true rejects further clicks until the 900ms mismatch timer completes.
  • Zero Ghost Flips: Pressing Restart mid-timer immediately invokes clearTimeout(), eliminating stale callbacks in the new game.
  • Duplicate Click Guard: Clicks on already revealed or matched cards exit early without penalty.

5. Multi-Device Responsive Architecture

  • Fluid Grid Tracks: Replaced unbounded 1fr with repeat(cols, minmax(0, 1fr)), guaranteeing all 6 columns fit inside the cabinet on mobile screens (320px–390px) with zero horizontal overflow.
  • Mobile Landscape Gaming Mode: Auto-compresses header padding and switches match celebration modal to horizontal layout, ensuring cards fit within 375px viewport height without scrolling.
  • Touch Ergonomics: Enforced touch-action: manipulation; (eliminating 300ms tap delay) and 44px+ tap targets.
